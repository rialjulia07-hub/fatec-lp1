## Configuração do Ambiente

### 1. Instalação do Python

Baixe o instalador em [python.org/downloads](https://www.python.org/downloads/) e, durante a instalação, marque
a opção **"Add python.exe to PATH"**.

Verifique a instalação abrindo um terminal e executando:

```bash
python --version
```

### 2. Instalação do VS Code

Baixe e instale o [Visual Studio Code](https://code.visualstudio.com/).

### 3. Extensões do VS Code

Instale as seguintes extensões pela aba *Extensions* (`Ctrl+Shift+X` no Windows/Linux, `Cmd+Shift+X` no macOS):

- **Python** (Microsoft) — suporte à linguagem, execução e depuração de scripts `.py`.
- **Jupyter** (Microsoft) — suporte à execução de notebooks `.ipynb`.

### 4. Configuração do Git (Opcional)

```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
```

### 5. Clone do repositório e configuração dos remotes

Cada aluno terá dois remotes configurados: o `origin`, apontando para o repositório do professor (de onde vêm o conteúdo e os exercícios), e o `dev`, apontando para o repositório próprio do aluno (para onde as resoluções serão enviadas).

```bash
# clona o repositório do professor
git clone https://github.com/professordezani/fatec-lp1.git
cd fatec-lp1

# confirma que o "origin" aponta para o repositório do professor
git remote -v

# adiciona o repositório do aluno como um novo remote chamado "dev"
git remote add dev <URL-do-repositorio-do-aluno>
```

### 6. Commit e push no repositório do aluno

```bash
git add .
git commit -m "resolve exercícios do tópico 01"
git push dev main
```
